# 开学报到

## 前往石家庄

### 火车 / 高铁

石家庄市有多个动车站（高铁站），但只有石家庄站和石家庄东站是有地铁站可快速到达学校的，如无其他必要原因，推荐选择在石家庄站下车

石家庄站(距学校21km)为普通火车+高铁站，石家庄东站(距学校10km)为高铁站

别忘了勾选学生票选项，<mark>普速火车硬座半价，高铁二等座 75 折</mark>，新生可以通过录取通知书证明学生身份

:::warning

买火车/高铁票请认准 12306，12306 从未与任何第三方平台合作，也没有将票额分配给任何第三方平台进行发售。铁路 12306 平台才是铁路部门唯一的官方售票渠道

车票于开车日期前 14 天开始售卖，每个站点的开票时间有所不同，别忘了定闹钟抢票

:::

:::tip

铁路禁带物品请见[国家铁路局 公安部关于公布《铁路旅客禁止、限制携带和托运物品目录》的公告](https://www.gov.cn/zhengce/zhengceku/2022-05/31/content_5693212.htm)

常见的学生可能有但禁带的：
- 剪刀、美工刀、水果刀（指甲刀不算）
- 充电宝（单个能量超过100Wh，即约27000mAh的）

:::

### 飞机

距离学校最近的为石家庄正定国际机场(17km)

:::tip

民航行李问题请见[中国民用航天局 - 航旅指南](https://www.caac.gov.cn/CXCK/HLZN/201512/t20151214_15867.html)

:::

## 前往学校

### 打车

对于行李较多的且初次抵达石家庄的同学，直接打车到学校是个不错的方案

推荐使用**支付宝 / 高德地图 / 滴滴出行 / 花小猪**线上打车，价格透明，线下打车极易遇到黑车，有相当多同学遭遇过黑车，遭受<mark>经济损失</mark>甚至<mark>人身骚扰</mark>，强烈不推荐线下出租车

打车从石家庄站到达河北地质大学需要70元左右

### 公共交通

如果你行李较少、且有足够的自信能够通过公共交通抵达学校，那么公共交通是极为经济实惠的

- 你可以在到达石家庄站后跟随路标指引，直接搭乘地铁2号线，到达北国商城站后，换乘1号线，到达会展中心站下车（2元）

- 到达会展中心后：
    - 搭乘814路公交直达学校（1元）
    - 打车到达学校（13元左右）
    - 骑乘共享电车到达学校（2.5-4元）
