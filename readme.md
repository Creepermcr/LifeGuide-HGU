# 河地大生活指南

LifeGuide-HGU

你的河北大道 601 号生活指南

使用 VitePress 构建，基于 [Survive-HFUT](https://github.com/Survive-HFUT/survive-hfut.github.io) 改编

## 安装依赖并运行

确保你已经安装了 [Node.js](https://nodejs.org/) 和 [pnpm](https://pnpm.io/)

```sh
# 进入目录
cd LifeGuide-HGU/

# 安装依赖
pnpm install

# 启动开发服务器（默认 http://localhost:5173）
pnpm run dev

# 构建文档，产物输出到 .vitepress/dist
pnpm run build

# 本地预览构建产物
pnpm run preview
```
