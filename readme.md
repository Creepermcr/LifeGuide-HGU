# 河地大生活指南

LifeGuide-HGU

你的河北大道 601 号生活指南

使用 VitePress 构建，基于 [Survive-HFUT](https://github.com/Survive-HFUT/survive-hfut.github.io) 改编

## 安装依赖并构建

确保你已经安装了[NodeJs](https://nodejs.org/)和[npm](https://www.npmjs.com/)

```sh
# 进入目录
cd /www/wwwroot/your-project

# 安装依赖
npm install

# 运行
npm run docs:dev

## 构建文档
npm run docs:build
```
